# task-management-app

## Tech Stack
- Backend: .NET Web API
- Frontend: Angular
- Database: SQL Server

## Features
- Create, update, delete tasks
- Mark tasks as completed
- Authentication (basic username/password)
- Sorting and filtering

## How to run backend
dotnet run

## How to run frontend
npm install
ng serve

## Database setup
Run TaskDb.sql in SQL Server
